figaro CLI verbs and RPC methods at v0.97.0

For Gluck to validate. Written 2026-11-27 by the Figaro Engineer (ethics-body). Source: tag v0.97.0 (72b1b183c).

Standing order (Gluck, 11-27): no new CLI verb or RPC method without Gluck's explicit permission. figaro note / figaro.note (v0.97.0) is the case that prompted it and is highlighted below. It stays as it is until Gluck rules.

How to read it. "Added" is the first commit whose diff adds the registration (the api/command table entry or verb("x" for verbs, the method-name string for RPC), and the earliest release tag that contains that commit. v0.1.1 means present in the first tag, not added in it: everything before 2026-05 shows as v0.1.1. The explanations for verbs are the binary's own one-line help. Most RPC methods have no doc comment in api/rpc, so their explanations were written for this page from the handler and the commit that added them. The tick box is for you; it does not save.
