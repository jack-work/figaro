Layout research: ELK's description of the Sugiyama framework and Healy and Nikolov, hierarchical drawing algorithms. This prototype uses our own pure layered-layout function, not ELK or a CDN. Implementation, limits and proposed Zanni port.

Production prerequisite: an open connection is not proof of a current authorized projection. Reconnect generation changes must reseed correctly; refused refresh must not leave the old authorized tree visible as current. Formista is preparing that state-client repair. No runtime calls, create actions, writes, storage or external dependencies.
