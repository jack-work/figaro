S0 figwal carve (shipped 0.58.3; from carve 1; lines -1,263 (measured))

Five packages under figwal/, nested-fork engine removed, boundary rule 2 tightened.

Breaks: import paths only.

needs nothing; gate: done

S1 delete one-shot migrations (proposed; from design H (first half), audit 11, review 7; lines about -1,000)

Delete figwal/xwal/flatten.go (571), internal/store/migrate.go (354), rename.go, NeedsFlatten, meta_heal.go if migration-only, and the generations they gate. A store older than layout 4 is refused with 'upgrade through 0.58.x first'. Drops the cli -> figwal/xwal allowlist edge.

Breaks: a store below layout 4 no longer opens. Gate: schema.json on gluck, spain and cheroot reports layout 4.

needs nothing; gate: doctor schema on three nodes; full suite; flake check.

S2 flatten the store contract (proposed; from design A (first half), review 1, audit 10; lines -600 to -900)

Delete store.Backend (40 methods, one implementation), the 38 local capability interfaces, the 64 type assertions and the no-capability branches (ErrNoTrunkCapability, topo.ErrNoPromote, topo.FromTopology, dem.Unsupported). Callers take the concrete type.

Breaks: nothing at runtime. Every open lane that touches store rebases once.

needs S1; gate: full suite x3 -race on store and angelus; T1 bench rows unchanged.

S3 split the store by layer (proposed; from design A (second half), carve 2; differs from review 2 (D1); lines -300 to -500 (forwarders))

Merge XwalStore into XwalBackend, then cut the result along the stack: runtime (logs, forms, residency), hierarchy (births, fork, promote, demote, arrange, normalize, ttl, reaped; internal/topo folds in), bindings (study, libretto, roles), host ops (meta, quarantine, memory, moves). Log[T] and Entry move to runtime so provider and decide import the runtime, never store (carve 2's rule as boundary rule 6). store stops importing turns, tokens and config.

Breaks: import paths only.

needs S2; gate: boundary rule added; full suite; IR read benches (ReadPage, TailBudgeted).

S4 one runtime layer (proposed; from design B, review 3 and 6, audit 9 and 12; lines -700 to -900)

segment, disk and log move under figwal/internal; log folds into disk (-400); one Log[T] (treeLog's cache into xwalLog, -500). Kind strings become opaque to figwal; moves leave xwal for federation. The public surface is primitives (aria, form), group commit, and two declared seams: Own and Prefix. angelus and cli stop importing figwal/xwal.

Breaks: import paths. Boundary rule 2 is replaced by Go's internal/ rule.

needs S3; gate: IR and form hot-path benches against the S3 release; crashtest.

S5 checkpointed reducible channel (proposed; from design C, review 4-5 (first half), audit 1 outcome, 3, 8; lines net negative only with audit 3 and 8 riding (D11))

A checkpoint file per reducible channel, one live segment of at most N patches, an MVCC version pointer cached in figwal/tree, a background checkpoint writer off the append lock. Forms move onto it; store.Form becomes a view (no second fold); system.seqs leaves the folded state. Delete the segment header mode, HeaderAt, SegmentHeaderAt, OnSegmentOpen, reseedEmptyActiveHeader, reducibleFold, the root watermark, seedEmptyLog. One form log type (audit 8) and one apply/diff (audit 3) ride along.

Breaks: ON DISK: layout 5, with a one-shot converter deleted one release later. A rollback below this release needs the pre-upgrade backup. Retention must keep your 11-04 rule (D9).

needs S4; gate: El Inspector reads the layout rule; crashtest; form write and rotation benches; a converter run on copies of gluck, spain and cheroot stores.

S6 owned primitives (proposed; from design E; lines at risk: must pay with deletions (D11))

runtime.Own(owner, spec); a private id namespace the router refuses; Open of an owned id by anyone but the owner refused; the owner is the GC root. Provider logs, librettos and caches move onto it, deleting their special cases (translation dir handling, libretto ids, gc carve-outs). Runs in parallel with S5.

Breaks: show and other tools that read provider logs read through the owner or a published version (open question D16).

needs S4; gate: authz tests: an owned id is Hidden from every caller; full suite.

S7a hierarchy: Prefix and Materialize (proposed; from design D1-D2, audit 6; lines -150 to -400)

disk.Log's Parent and forkBase are replaced by an injected Prefix (Read, StateAt, Last). Materialize(below) replaces absorb-on-delete. Nested fork directories and hasSubdirs go: the per-append ReadDir (about 4 of 5 us per append) leaves the hot path.

Breaks: ON DISK: fork directories flattened (layout bump, converter). Fork reads through parents are hot: bench them.

needs S5; gate: IR ReadPage, TailBudgeted, ForkWith benches; crashtest; El Inspector (layout).

S7b hierarchy: fork state as one form (proposed; from design D3, review 4 (second half), review 6; lines large negative (five places, six clocks))

Fork state becomes the hierarchy's own reducible form: child -> {parent, base per primitive} plus drawn edges. It replaces the .fork and .node markers, the index's lineage half, @topology, and the six clocks; the topo tree algorithm (moved in S3) runs over the form. adopt (#72) and role succession become sets on that form.

Breaks: ON DISK: markers retired (converter). Client epoch TopologyRev changes meaning: the pager follows the form version.

needs S7a; gate: El Inspector; promote/demote/succeed e2e in tmux; topology benches (topo-perf rows).

S7c hierarchy: ForkPoints (proposed; from design D4; lines small negative)

Bindings implement ForkPoints(id, at) -> {primitive: index}, replacing the x-join's main-LT stamping on every channel. The WAL keeps only group commit.

Breaks: nothing visible; forks of old stores read the stamps once through the converter.

needs S7b; gate: fork at every turn of a recorded tape; byte-identical provider requests after fork.

S7d module manifest and registry (proposed; from design D5-D6, carve 7 (first half); lines negative if per-verb tables in angelus fold into registrations)

The store manifest names the modules that wrote it; a store written with hierarchy cannot open without it. Each module registers its RPC verbs, default grants and CLI command set; the API advertises modules. Build sets follow (a figarod without hierarchy or federation), one nix output per set.

Breaks: packaging: new nix outputs. A client older than this release sees no advertisement and keeps today's verbs.

needs S7c; gate: El Inspector (grants per module); a no-hierarchy build passes the runtime and bindings suites.

S8 run(drained inbox) -> ops (proposed; from design F; lines positive unless the bash harness ships outside the main module (D11))

Bindings call run(drained inbox) and apply the returned ops (records, form patches) as one group commit. Tool calls run async and return through the inbox. The bash harness is the second run.

Breaks: interrupt semantics (D16: commit what streamed, or nothing).

needs S6; gate: tape replays byte-identical; steering and queued-send e2e.

S9 the agent owns provider logs (proposed; from design G; lines negative (two translation paths become one))

CatchUp moves out of each provider (anthropic.go, openaichat.go, responses.go) into the agent step; providers are pure encoders. Delete store/translate_on_append.go (129) and provider/on_append.go (91). Recovery truncates derived rows past the fig IR tail.

Breaks: translation format version bump only if output changes; retranslation must stay byte-identical (prompt cache).

needs S6, S8; gate: byte-identical requests over the tape corpus; cache-read rows in perf-baseline.

S10 final deletions (proposed; from design H (rest), review 8, audit 13; lines negative)

The layout converters of S5, S7a and S7b; translations v1 directories; caches left without a reader; one cache budget (segment payloads, tree, form window, raw page).

Breaks: a store must have passed the converter releases.

needs S9; gate: doctor schema clean on gluck, spain, cheroot.

K1 client binary (proposed; from carve 4; lines near zero; pays with the 23 allowlist edges)

Cut the 23 allowlisted edges: key constants to api/form, a models.list RPC, doctor's offline open behind figarod, dressing preview over RPC. cmd/figaro becomes client-only and cmd/figarod the daemon. Self-spawn execs figarod and becomes unit-aware (#60).

Breaks: figaro --angelus; the figarod symlink; install.sh, nix outputs, the home-manager module, vendorHash. sdk paths kept.

needs nothing; gate: El Inspector (spawn path, after the 11-05/11-06 spawn-env incidents); tmux run of both binaries.

K2 split cli (proposed; from carve 4, terraform 1.1; lines must pay with dead code in the 52k-line package)

internal/cli splits into cli (verbs), pager (transcript, pit, form view, render) and input (lineedit, keymap).

Breaks: nothing outside the binary.

needs K1; gate: tmux suites for pager and composer; modal-input rules.

K3 command sets per module (proposed; from design D6; lines small)

The client reads the advertised modules and loads one command set per module: without hierarchy, new, send, state; with it, fork, ls tree, promote, demote, kill -r, succeed.

Breaks: help text and completion depend on the server.

needs K2, S7d; gate: tmux against a no-hierarchy figarod.

X1 tools through api/sandbox (proposed; from carve 5; lines small negative)

internal/tool stops calling sandbox/local.NewHost and reaches every sandbox through api/sandbox. ExecRequest gains RunAs (#38). A figbox binary for the box side.

Breaks: the box serve entry point.

needs nothing; gate: El Inspector (sandbox boundary); the #39 probe table as a regression test.

X2 sandbox identity and leased grants (design needed; from captains-log 11-09 (leases, lineage grants), #39, #57, #56; lines design first)

A door per box that stamps a sandbox principal; leased boxes bound to a figaro's grant set; a child never gets more than its parent; a privileged reserved block in the bound form that the parent edits.

Breaks: to be designed.

needs X1, S7d; gate: El Inspector; multi-model audit like E1 step 3.

#74 study another figaro's bound form (forkcomment)

folds into S3: study.go and libretto.go move to bindings in S3; the policy change (admit kind figaro for study, refuse self, read grant, key prefix) is small either side of it. Under S6 a bound form is an actor primitive, so it is studyable by construction; the libretto is the observer's owned primitive.

#73 usage: IR output records lack model, provider, cache TTL, request start

independent; land before S9: Additive fields on the output record and the round span. Land before S9 so the agent step that S9 builds already carries them; S9 moves where they are recorded, not what.

#72 adopt: reparent a turn-0/1 fork

folds into S7b: Drawn edges live in the hierarchy form, so adopt is one set on it. Building it today adds a seventh place that knows topology.

#71 system.retirement at a context threshold, then ttl

independent; touches S7b, D13: Refusing new messages is inbox policy (bindings). The ttl-after-retirement rides whatever owns the reaper: ttl.go today, the root declarations after D13.

#70 derived forms (@roles)

easier after S3, S5: Roles and role_scan move to bindings in S3; published versions (S5) give a derived form a cheap input. A module that registers derived forms belongs in the S7d registry.

#68 authz: send-only grants unusable from the CLI

independent S7d: A host and CLI fix today. Per-module verb registration (S7d) is where send and attach get separate grants by construction.

#66 provider: mid-turn thinking_effort change

independent; fits S9: The fix (emit a row when effort differs from the previous message) is a pure-encoder rule from the stored log, which is exactly S9's shape. It changes translation output: bump the format version, and S9's drop-and-retranslate covers old logs.

#60 cli: self-spawn races the systemd unit

folds into K1: K1 makes self-spawn exec figarod; make it unit-aware in the same step.

#57 tool identity: unboxed tools reach the daemon as the owner

blocked by X1, X2: Needs a per-aria door, which is X2's sandbox identity.

#56 shell bindings keyed by principal and pid

folds into D14: Shell bindings are per-session state; keyed by (principal, pid) they become a session primitive.

#51 config.toml include or drop-in

independent; helps S7d: internal/config is shared by both binaries. Each registered module will declare its config table; a drop-in rule (config.d, error on a table defined twice) is the merge that registry wants. Can land now.

#47 authz: narrow door for service principals

folds into S7d: Splitting create falls out when runtime registers form.create and bindings registers aria create as separate verbs. target-of needs roles (bindings) as a fact source.

#45 socket drop: slow-RPC logging, stack capture, hush lifecycle

independent S7d: Unrelated to the layering. One help: once every verb registers through the S7d registry, slow-RPC timing has one wrapper.

#39 bwrap: allow-list mounts; a box that calls back is not the user

blocks X1, X2: Its probe table is X1's regression test. Lineage grants on boxes (X2) are hollow until a box is not the user.

#38 per-aria execution identity (RunAs)

folds into X1: RunAs on ExecRequest is part of routing tools through api/sandbox.

#28 system.index.name, richer list, search

partly blocked S7b, X2: The list columns (fork point, name) are client work now. Keeping the name unwritable by the aria needs the reserved block (X2).
