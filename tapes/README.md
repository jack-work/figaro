# tapes/SCENES.md — the catalog

Scene catalog and run book for the figaro demo tapes: 19 scenes across five
acts, each a scripted tmux capture of the real binary in a real pty. Style
reference: the Obel Mono launch tape (60s, 1080p60, hard cuts on a bar grid,
bold text cards between terminal segments).

Start here: read `SCENES.md` before any capture. It holds the capture
discipline (share-hush shell, clean pane rc, empty store, pager auto-promote
traps) and the scene index with beats and scripts. The edit plan (music,
BPM grid, cut structure) lives at the bottom of the same file.
