# Historical notes

Records of work that is finished or abandoned. **Verify before trusting
anything here.** These files were true when written and are not maintained.

They are kept for their reasoning and their measurements, which are expensive
to reproduce and occasionally still decisive. They are not kept as a
description of the code.

If you find yourself relying on one of these to answer a question about how
figaro behaves today, that is a signal the answer belongs in
[../reference/](../../reference/), freshly checked against source.

| File | What it is |
|---|---|
| `transcript-perf.md` | The five-axis transcript performance campaign, measured end to end against a fixed baseline. The axes shipped. |
| `transcript-paging.md` | The paging policy record: what the pager holds, when it fetches, what it discards, and the measurements behind the geometry. |
| `tool-render-refactor.md` | A plan for generic tool rendering. Not built, and the branch it names no longer exists. |
